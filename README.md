# 📊 Automated Data Analyzer on Google Colab

[![Open In Colab](https://google.com)](https://google.com)

A simple Python repository designed to demonstrate native **Google Colab** features for automated and interactive data analysis. 

This project allows any user to upload a spreadsheet (CSV or Excel), adjust analysis parameters visually using UI forms, and automatically export a summary report to Google Drive.

## 🛠️ Google Colab Features Used

*   **`google.colab.files`**
*   **Colab Forms (`@param`)**
*   **`google.colab.drive`**

## 📦 Required Packages

```bash
pip install pandas openpyxl
```

## 🚀 How to Run the Project

1. Click on the **"Open In Colab"** badge at the top of this page.
2. Run **Cell 1** to install dependencies and upload any `.csv` or `.xlsx` file from your local machine.
3. Adjust the visual parameters in **Cell 2**.
4. Run **Cell 2** to see your dataset analysis generate instantly!
